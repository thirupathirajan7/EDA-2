# Superstore Sales Analysis

## Project Overview

This project analyzes the Superstore dataset using Python, Pandas, Matplotlib, and Seaborn. The analysis focuses on sales, profit, discount, categories, and numerical relationships.

## Tools Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook

## Analysis Performed

* Displayed the first 5 rows of the dataset
* Created a bar plot for total sales by category
* Created a box plot to visualize profit distribution
* Created a scatter plot between discount and profit
* Created a correlation matrix for numerical columns
* Created a heatmap to visualize correlations
* Identified the category with the highest total profit

## Business Insights

1. **Technology is one of the most profitable categories**, showing strong contribution to overall business profit.

2. **Higher discounts can affect profit negatively**, so businesses should carefully manage discount levels to maintain profitability.

3. **Sales and profit are related**, meaning categories or products with higher sales can contribute significantly to overall profit, although high sales do not always guarantee high profit.

## Conclusion

The analysis helps understand sales and profit patterns and provides useful insights for better pricing, discount, and category management decisions.
